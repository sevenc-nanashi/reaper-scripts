# sevenc-nanashi/reaper-scripts

REAPER用のReaScript集。

## インストール

REAPERの「Extensions → ReaPack → Import repositories」で次のURLを登録します。

```text
https://raw.githubusercontent.com/sevenc-nanashi/reaper-scripts/main/index.xml
```

「Browse packages」から必要なスクリプトをインストールしてください。

## スクリプト

- `color_midi_item_by_pitch.lua`: MIDIアイテムのテイクのピッチ設定に応じて色を更新します。Action Listから実行すると、停止するまで監視を続けます。
